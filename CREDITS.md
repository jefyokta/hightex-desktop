# Credits

HighTex Desktop brings together work from its contributors and the open-source projects that support its thesis-writing workflow.

## Creator and Maintainer

- **[Jepi Okta Mipa (jefyokta)](https://github.com/jefyokta)** — creator of HighTex and maintainer of HighTex Desktop.

HighTex began as a final-year project in the Information Systems program at UIN Sultan Syarif Kasim Riau. See the [project background](./README.md#why-hightex) for its origins.

## Open-Source Projects

Thank you to the authors and maintainers of the libraries and tools used by HighTex Desktop, including:

| Project                                                                                      | Used for                                |
| -------------------------------------------------------------------------------------------- | --------------------------------------- |
| [Electron](https://github.com/electron/electron)                                             | Desktop application runtime             |
| [React](https://github.com/facebook/react)                                                   | Application interface                   |
| [TypeScript](https://www.typescriptlang.org/) and [Vite](https://vite.dev/)                  | Application development and builds      |
| [Tiptap](https://tiptap.dev/)                                                                | Rich-text editor and extensions         |
| [shadcn/ui](https://ui.shadcn.com/)                                                          | Primary UI component system             |
| [Tailwind CSS](https://tailwindcss.com/)                                                     | Utility-based styling                   |
| [Radix UI](https://radix-ui.com/primitives)                                                  | Underlying primitives for UI components |
| [Lucide](https://lucide.dev/)                                                                | Interface icons                         |
| [Geist via Fontsource](https://fontsource.org/fonts/geist)                                   | Interface typography                    |
| [KaTeX](https://katex.org/)                                                                  | Mathematical notation                   |
| [Paged.js](https://pagedmedia.org/) and [pdf-lib](https://pdf-lib.js.org/)                   | Document pagination and PDF processing  |
| [Citation.js](https://citation.js.org/) and `bibtex.js`                                      | Citation and bibliography handling      |
| [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) and [Dexie](https://dexie.org/) | Local data storage                      |
| [Zustand](https://github.com/pmndrs/zustand)                                                 | Application state management            |
| [electron-builder](https://github.com/electron-userland/electron-builder)                    | Application packaging and distribution  |

See [package.json](./package.json) for the project's direct dependencies and development tools. Each dependency includes its own license and attribution information.
