# Merujuk Figure dan Persamaan

Figure, table, dan persamaan yang terdapat di dalam dokumen dapat dirujuk menggunakan **Reference**.

## Manual

Tekan pengaturan pada **figure, table, atau persamaan** yang ingin dirujuk, kemudian pilih **Copy Ref**. Setelah itu, paste reference tersebut di lokasi yang diinginkan.

## Via Suggestion

Reference juga dapat ditambahkan melalui **Suggestion** menggunakan shortcut berikut:

| Shortcut | Reference                                  |
| -------- | ------------------------------------------ |
| `/table` | Menampilkan daftar table yang tersedia     |
| `/img`   | Menampilkan daftar image yang tersedia     |
| `/eq`    | Menampilkan daftar persamaan yang tersedia |

Setelah shortcut dipilih, akan muncul **popup** yang berisi figure, table, atau persamaan yang tersedia di dalam dokumen. Pilih item yang ingin dirujuk untuk memasukkan reference ke dalam dokumen.
