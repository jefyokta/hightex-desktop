# Persamaan

Persamaan digunakan untuk menuliskan rumus atau ekspresi matematika menggunakan sintaks **LaTeX**.

## Shortcut

Gunakan format berikut untuk membuat persamaan:

```text
$$ LaTeX $$
```

Contoh:

```text
$$ E = mc^2 $$
```

## Rujukan

Setiap persamaan yang dibuat **harus dirujuk** di dalam dokumen.
