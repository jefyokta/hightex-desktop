# Presentasi Dokumen

Fitur **Presentasi Dokumen** digunakan untuk menampilkan dokumen kepada audience, misalnya untuk keperluan **bimbingan** atau **seminar**.

Presentasi menggunakan **jaringan lokal (LAN)**. Pastikan perangkat kamu dan audience berada pada **jaringan yang sama** agar dapat terhubung dan melihat presentasi.

## Upcoming Feature

Dukungan untuk melakukan presentasi melalui **internet** sedang direncanakan, sehingga audience dapat terhubung tanpa harus berada di jaringan lokal yang sama.
