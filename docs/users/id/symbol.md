# Symbol Variable

**Symbol Variable** digunakan untuk memasukkan simbol yang umum digunakan tetapi tidak tersedia secara langsung pada keyboard.

Pengguna dapat memasukkan simbol dengan mengetik `\` diikuti nama variable yang sesuai.

## Cara Penggunaan

Contoh, untuk memasukkan simbol alpha, ketik:

```text
\alpha
```

Hasilnya:

```text
α
```

Contoh penggunaan di dalam teks:

```text
Nilai alpha dilambangkan dengan \alpha.
```

Hasilnya:

```text
Nilai alpha dilambangkan dengan α.
```
