# Variable

Variable digunakan untuk menyimpan nilai yang dapat digunakan kembali di dalam dokumen.

## Shortcut

Gunakan shortcut `\` untuk menampilkan dan memilih variable yang tersedia.

## Built-in Variable

HighTex menyediakan beberapa **global variable** bawaan yang tidak dapat di-override oleh pengguna, tetapi nilainya tetap **dynamic** dan akan menyesuaikan dengan data dokumen.

| Variable       | Value                                      |
| -------------- | ------------------------------------------ |
| `title`        | Judul dokumen                              |
| `altTitle`     | Judul dokumen dalam bahasa Inggris         |
| `chapter{num}` | Judul chapter berdasarkan kategori dokumen |

> `chapter{num}` menggunakan nomor chapter sebagai parameter, misalnya `chapter1` untuk mendapatkan judul chapter pertama.

## Menambah dan Melihat Variable

Untuk menambah atau melihat variable yang tersedia:

1. Buka **Sidebar**.
2. Pilih tab **Variable**.
3. Tambahkan variable baru atau lihat variable yang sudah tersedia.
